# 5 — GitHub Copilot

## Objective
Demonstrate the use of GitHub Copilot to generate or assist with project code and document the result.

## Procedure
1. Select one small, meaningful coding task from the project.
2. Open the project in VS Code with GitHub Copilot enabled.
3. Give Copilot a clear prompt for the selected task.
4. Capture a screenshot showing the Copilot suggestion/generation.
5. Review the generated code and make any required corrections.
6. Run the application or relevant test to verify the change.
7. Commit the accepted code to GitHub.
8. Capture the final repository/commit evidence.

## Evidence to collect
- `01_Copilot_Prompt.png`
- `02_Copilot_Generated_Code.png`
- `03_Reviewed_Code.png`
- `04_Test_Result.png`
- `05_GitHub_Commit.png`

## Important
Do not claim that Copilot generated code unless the screenshot/evidence actually shows Copilot being used.
