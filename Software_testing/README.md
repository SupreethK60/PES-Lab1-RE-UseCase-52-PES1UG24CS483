# 6 — Software Testing Tools

## Objective
Test the faculty-provided game application, identify the supplied bug/failing behavior, use vibe coding to fix it, apply the patch, and retest.

## Process
1. Obtain the faculty-provided game repository.
2. Read its README completely.
3. Understand what the game does.
4. Identify the four supplied test cases.
5. Run the application and execute the four test cases.
6. Record the observed results.
7. Identify the failing test/bug.
8. Use vibe coding/GitHub Copilot to develop a fix.
9. Review and apply the patch.
10. Run the relevant test again.
11. Run all four test cases again to check for regressions.
12. Commit and push the fixed code.
13. Record the final repository link.
